## Selection guidance

- Start with Business Analysis when requirements are unclear.
- Use Software Architecture for cross-cutting or multi-component changes.
- Pair implementation skills with QA and Testing for code delivery.
- Include Cybersecurity and DevOps for production-facing systems.
- Add Technical Documentation to work that changes interfaces, operations, or architecture.
- For a small, isolated task, use one focused skill rather than a large bundle.
