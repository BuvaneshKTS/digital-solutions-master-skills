# Design Review

Score each dimension from 1 to 5: product fit, originality, hierarchy, composition, typography, color and contrast, component consistency, usability, responsive behavior, accessibility, and scope discipline.

Revise if product fit, hierarchy, usability, or accessibility scores below 3. A total below 36/55 means rethink the concept or composition.

Review sequence:
1. Describe the visual concept in one sentence.
2. Identify the strongest design decision.
3. Identify the three weakest areas by user impact.
4. Find generic patterns and unnecessary decoration.
5. Verify all requested content and actions remain.
6. Revise the weakest areas and review again.

For redesigns, check that the result improves beyond spacing, shadows, borders, and color; that the composition is stronger; that the primary action is easier to find; and that no unrequested content was added.

Scores are heuristics, not objective usability measurements. Never fabricate user testing.
