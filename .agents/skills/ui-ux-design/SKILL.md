# UI/UX Design

## Mission
Design useful, understandable, inclusive experiences grounded in user needs.

## Workflow
Start with audience, jobs-to-be-done, context, constraints, and success measures. Map journeys and information architecture before visual polish. Define content hierarchy, interaction states, navigation, responsive behavior, and design tokens. Prefer consistent patterns and clear affordances. Include accessibility: semantic controls, keyboard flow, focus, contrast, scalable text, and understandable errors. Validate with prototypes and representative tasks; record observed usability issues rather than relying only on subjective preference. Deliver flows, component/state specifications, responsive guidance, and acceptance criteria.

## Quality checklist
- [ ] User needs and primary journeys are clear.
- [ ] Loading, empty, error, success, and validation states are designed.
- [ ] Responsive layouts and accessibility are considered.
- [ ] Components and visual tokens are consistent.
- [ ] Usability assumptions are validated or clearly labeled.

## Creative design workflow
For substantial visual tasks, explore three distinct directions internally before choosing one. Directions must differ in composition and visual language, not just accent color. Write a one-sentence design thesis and explain why it suits the product and audience.

Do not default to a stack of rounded cards. Consider editorial layouts, asymmetric compositions, split panels, focused task areas, modular grids, and other structures when they better support the content. Use visual weight, typography, whitespace, alignment, and contrast to establish hierarchy before decoration.

For screenshot redesigns, preserve required content and functionality but challenge weak layout decisions. If the user says not to add anything, do not add features, metrics, navigation, or sections. A redesign should improve composition and identity, not merely shadows, borders, gradients, and spacing.

Before delivery, inspect the result at its intended viewport and review the relevant references:
- `references/creative-direction-playbook.md`
- `references/visual-craft-and-composition.md`
- `references/dashboard-design-patterns.md`
- `references/design-review.md`

Reject generic templates, repetitive card walls, decorative noise, tiny low-contrast labels, and unrequested content. Iterate when hierarchy, product fit, originality, or responsive behavior is weak.
