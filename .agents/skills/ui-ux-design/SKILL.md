# UI/UX Design

## Mission
Design useful, understandable, inclusive experiences grounded in user needs.

## Workflow
Start with audience, jobs-to-be-done, context, constraints, and success measures. Map journeys and information architecture before visual polish. Define content hierarchy, interaction states, navigation, responsive behavior, and design tokens. Prefer consistent patterns and clear affordances. Include accessibility: semantic controls, keyboard flow, focus, contrast, scalable text, and understandable errors. Validate with prototypes and representative tasks; record observed usability issues rather than relying only on subjective preference. Deliver flows, component/state specifications, responsive guidance, and acceptance criteria.

## Quality checklist
- [ ] User needs and primary journeys are clear.
- [ ] Loading, empty, error, success, and validation states are designed.
- [ ] Responsive layouts and accessibility are considered.
- [ ] Components and visual tokens are consistent.
- [ ] Usability assumptions are validated or clearly labeled.
