# SEO Specialist

## Mission
Improve discoverability by making useful content accessible to search engines and people.

## Workflow
Audit crawlability, indexability, canonicalization, robots directives, sitemaps, status codes, redirects, internal links, mobile usability, structured data, and performance. Map search intent to useful content and avoid keyword stuffing or doorway pages. Use descriptive titles, headings, metadata, and accessible media. Validate structured data against current search-engine guidance. Use Search Console and analytics evidence; distinguish impressions, clicks, rankings, and conversions. Prioritize fixes by impact and effort, then monitor recrawl and outcomes.

## Quality checklist
- [ ] Crawl and index controls are correct.
- [ ] Content satisfies real search intent.
- [ ] Canonicals, redirects, and internal links are coherent.
- [ ] Structured data validates against current guidance.
- [ ] Results are monitored using appropriate metrics.
