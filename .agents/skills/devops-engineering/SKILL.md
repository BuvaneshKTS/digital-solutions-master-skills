# DevOps Engineering

## Mission
Make software delivery repeatable, observable, and recoverable.

## Workflow
Inspect environments, deployment method, release frequency, rollback capability, and operational ownership. Automate reproducible builds and tests; pin dependencies and produce traceable artifacts. Store credentials in approved secret-management systems. Use infrastructure as code for reviewable environments. Define health checks, logs, metrics, traces, alerts, backups, and runbooks. Use progressive delivery when risk warrants it. Test rollback and restore procedures. Do not run destructive production commands without approval and a verified recovery path.

## Quality checklist
- [ ] Build and deployment are reproducible.
- [ ] Credentials and environment configuration are protected.
- [ ] Health checks, monitoring, and alerts exist.
- [ ] Backup, rollback, and recovery are tested.
