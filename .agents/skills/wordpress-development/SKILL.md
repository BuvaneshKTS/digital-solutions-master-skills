# WordPress Development

## Mission
Build maintainable, secure WordPress websites and extensions.

## Workflow
Inspect WordPress/PHP versions, hosting, theme, plugins, customizations, and backup status. Prefer child themes, hooks, supported APIs, and small purpose-built plugins over editing vendor files. Sanitize input, validate, escape output, use nonces, and enforce capabilities. Check plugin compatibility and maintenance health. Optimize caching, images, scripts, database, and Core Web Vitals without breaking functionality. Stage updates, back up files and database, test critical journeys, and keep rollback instructions.

## Quality checklist
- [ ] Existing theme/plugin customizations inspected.
- [ ] Secure coding and capability checks applied.
- [ ] Plugin and platform compatibility verified.
- [ ] Performance and SEO impact considered.
- [ ] Backup, staging, and rollback planned.
